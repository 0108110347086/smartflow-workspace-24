# AI Workspace Hub

1. Role

Tell the AI who it should act as.

“Act as a senior full-stack developer and UI/UX designer.”

2. Goal

Clearly explain what you want to create or achieve.

“Build an AI-powered productivity website.”

3. Context

Give the AI the background and purpose.

“The platform is designed to help users manage meetings, tasks, schedules, and research in one workspace.”

4. Requirements

List exactly what the project must include.

Meeting Notes Summarizer

AI Task Planner

Calendar/Scheduler

AI Research Assistant

Projects

AI Chat Assistant

5. Integration

Explain how the features should work together.

“Meeting action items should automatically become tasks, tasks should be schedulable on the calendar, and research should be linked to relevant projects and tasks.”

6. User Experience

Describe how you want it to look and feel.

“Use a clean, modern SaaS design with a responsive dashboard, sidebar navigation, cards, tables, calendars, search, and dark/light mode.”

7. Pages / Screens

Tell it which screens to create.

Landing Page → Login → Dashboard → Meetings → Tasks → Calendar → Research → Projects → AI Assistant → Settings

8. Functionality

Explain what users should be able to do.

“Users can upload meeting notes, generate summaries, edit AI results, create tasks, schedule tasks, conduct research, save findings, and link everything to projects.”

9. Technical Requirements

Specify the technology and architecture, if you have preferences.

“Use a modern frontend, backend API, database, authentication, AI API, secure environment variables, and responsive design.”

10. Rules / Constraints

Tell the AI what it must and must not do.

“Do not create disconnected features. Keep user data private. Never expose API keys. Require confirmation before important AI actions.”

11. Output / Deliverable

Be clear about what you expect at the end.

“Build a complete working application, not just a visual mockup. Test the main user flows and fix errors.”
